# Bow and Elementals

Браузерная roguelike-игра на выживание. Лучник сам стреляет в ближайшего врага, а вы бегаете, уворачиваетесь, собираете опыт и выбираете улучшения. Цель — продержаться 2 минуты против толп стихийных существ и двух боссов.

Игра написана на чистом JavaScript и Canvas, без библиотек и сборки.

## Как запустить

Скачайте репозиторий и откройте `index.html` в браузере. Установка не нужна.

```bash
git clone https://github.com/pabl0ki/bow-and-elements.git
```

Если удобнее запускать через локальный сервер:

```bash
python -m http.server 8765
```

После этого игра доступна по адресу `http://localhost:8765`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | `WASD` или стрелки |
| Рывок (во время него лучник неуязвим) | `Shift` или `Пробел` |
| Пауза | `Esc` или `P` |
| Выбор улучшения при новом уровне | `1`–`3` или клик по карточке |
| Начать игру | `Enter` |
| Выбор стихии в меню | `Q` / `E` или клик |
| Покупка улучшений в меню | `1`–`4` или клик |
| Продолжить в бесконечном режиме после победы | `C` |
| Выйти в меню с экрана паузы или конца игры | `M` |

## Что есть в игре

- **Стихийные стрелы.** Перед раундом выбирается стихия:
  - огонь поджигает и наносит урон со временем;
  - лёд замедляет врагов;
  - молния перескакивает на соседних врагов.
- **Прокачка в раунде.** Враги роняют кристаллы опыта. На каждом новом уровне игра предлагает одно из трёх случайных улучшений: дополнительные стрелы, пробивание, регенерацию, усиление стихии и другие.
- **Прокачка между раундами.** Собранный опыт сохраняется и тратится в меню на здоровье, урон, скорострельность и скорость бега.
- **Четыре вида врагов:** быстрый, крепкий, стрелок, который держит дистанцию, и боссы.
- **Два босса** на 0:40 и 1:20. У каждого свои атаки: кольцо снарядов, веер и рывок, перед которым загорается красная полоса.
- **Бонусы на карте:** лечение, урон и скорострельность.
- **Бесконечный режим.** После победы можно продолжить: враги с каждой минутой становятся намного сильнее, а боссы приходят каждые 45 секунд. В общий опыт идёт 10% опыта, собранного в этом режиме.
- **Большая карта** с камерой и мини-картой, рекорды по времени, убийствам и уровню.

Прогресс (опыт, улучшения, рекорды, выбранная стихия) хранится в браузере, в `localStorage`. Если очистить данные сайта, прогресс пропадёт.

## Режим отладки

Нужен, чтобы быстро проверять изменения. Включается клавишей `F2` или адресом с `?debug` (например, `index.html?debug`). Справа появляется панель со счётчиком кадров, числом объектов и списком клавиш.

В игре:

| Клавиша | Действие |
| --- | --- |
| `1` | +1 уровень |
| `2` | перемотать время на 15 секунд |
| `3` | призвать босса |
| `4` | убить всех врагов |
| `5` | полное лечение |
| `6` | бессмертие |
| `7` | +10 врагов |
| `8` | случайный бонус на карте |
| `9` | сменить стихию |
| `0` | показать хитбоксы |

В меню: `X` даёт 1000 опыта, `R` сбрасывает весь прогресс.

Если в забеге использовались эти клавиши (кроме показа хитбоксов), его опыт и рекорды не сохраняются.

## Как устроен код

Вся игра лежит в двух файлах:

- `index.html` — страница с холстом, который подстраивается под размер окна;
- `script.js` — вся логика и отрисовка.

Разделы `script.js` идут в таком порядке: настройки и баланс, картинки и спрайты, сохранения, магазин, стихии, улучшения, боссы, состояние игры, камера, управление и отладка, эффекты, враги, кристаллы, стрельба, игрок и его анимации, бонусы, интерфейс, главный цикл.

Основные цифры баланса собраны в начале файла в объектах `GAME` и `BALANCE`: длительность раунда, число врагов, рост их здоровья, параметры бесконечного режима. Цены магазина задаются в `UPGRADES` и `UPGRADE_COST_MUL`, улучшения раунда — в `LEVEL_OPTIONS`, боссы — в `BOSS_TYPES`.

### Графика

- `лучник.png`, `enemy1.png`, `enemy2.png`, `back2.jpg` — готовые картинки.
- Стрелок и оба босса нарисованы кодом при загрузке игры (раздел «Спрайты, нарисованные кодом»).
- У лучника один кадр. Для бега картинка разрезается на корпус и две ноги, которые двигаются отдельно; остальные анимации (отдача, рывок, урон, смерть) сделаны поворотом и масштабом.
